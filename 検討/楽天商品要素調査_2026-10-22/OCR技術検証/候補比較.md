## 選定

**最初に試す候補: PaddleOCR 3.7.0 + PaddlePaddle 3.3.1 CPU。**

- GitHub starsが比較した4 OCR project中最多（約91.5k）。人気指標での代表性を選ぶ基準にした。
- PaddleOCR 3.7.0は直近releaseで、日本語を含むPP-OCRv6を告知している。
- Python 3.12 Windows x64向けCPU wheelが公式PyPIで確認できるため、対象環境との主要な互換性リスクが解消している。実際のimport・推論可否はSTEP 02の導入で確認する。
- PADDLE_PDX_CACHE_HOMEとpip/TEMP/TMPの保存先を検討フォルダーへ向ける計画が可能。初回モデル取得後、実際のpathが外部へ逸れていないかをSTEP 02で確認する。
- starsではPaddleOCR、ダウンロード数ではpytesseractが最大であり、「最もメジャー」は指標に依存する。pytesseractの数字はwrapper配布数なので、GitHub starsで最大のOCR projectを代表候補に採用する。PyPI取得数は補助指標として併記する。

**次点: RapidOCR 3.10.0。** PaddleOCRのCPU runtime、モデル取得または保存先隔離が対象環境で実行できない場合に移る。最新releaseが新しく、日本語対応モデルを持ち、公式wheelにモデルが含まれるため隔離構成が単純。切替が必要になったらSTEP 02で理由を記録する。Tesseractはstars第2位だがWindows native executable/DLLと日本語traineddataを個別に隔離する作業が追加になるため、今回の簡易なローカル検証ではRapidOCRを次点にする。
