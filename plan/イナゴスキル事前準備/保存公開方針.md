## 保存場所

原観測・本文全文・IDの対応を扱う作業データは、作業ルート直下の`非公開作業データ/`へ保存します。実行計画共通部の保存先はこの場所を明記していましたが、STEP 05の個別手順だけが`plan/`内を指していました。別の保管場所ができないよう、データを作る前に計画中の該当手順を作業ルート直下の場所へ修正し、共通パスに統一しました。

| ディレクトリ | 用途 | 公開範囲 |
| --- | --- | --- |
| `非公開作業データ/原観測/` | ROOM画面の必要な読み取り値、取得参照、観測IDの記録 | ローカル限定 |
| `非公開作業データ/基礎/` | 当日基礎結果と検索記録。本文は同ディレクトリの`本文/`へ分離 | ローカル限定 |
| `非公開作業データ/補足/` | 不足時のG01～G05の検索別結果、重複参照、使用枠 | ローカル限定 |
| `非公開作業データ/統合/` | 基礎・補足を重複区分した分析用記録 | ローカル限定 |
| `非公開作業データ/投稿者対応/` | 公開プロフィール参照とA0001等の匿名別名との必要最小限の対応 | ローカル限定。名前等の不要情報を写さない |
| `非公開作業データ/本人提供/` | 本人が追加で渡した資料の受領原本と出典・用途 | ローカル限定 |
| `非公開作業データ/画面記録/` | 必要欄だけを残した表示確認用画像・説明 | ローカル限定 |

Git除外の動作を確かめる一時確認ファイル以外、STEP 05時点で実標本や本人資料をこの保存先へ入れていません。将来の原観測は、確定したフォルダ区分と検索／観測IDから辿れる形で保存します。

## 収集・表示の扱い

- 投稿者は`A0001`からの連番別名で集計します。プロフィール対応が分析に要る時だけ別ファイルへ保存し、公開用の資料・索引・HTMLへ実名を出しません。
- 他者の本文全文は文型・文字数の分析に必要な作業記録だけへ保存します。成果物・レポートでは構造の要約、匿名の母数・参照ID、本人が書いた例文を用い、本文を再配布しません。
- 画像は必要な欄が読める範囲でのみ保存します。本人のログイン状態、ブラウザプロファイル、Cookie、トークン、認証情報は含めません。不要な投稿者名・個人情報を避けるために全画面キャプチャを残さず、限定切り抜きで足りる時はその範囲に留めます。
- 公開資料には、検証に必要な集計・定義・実施結果・実際の検証方法と範囲を記載します。非公開原観測がない読者にも結論と限界が読める本文とし、ローカル参照リンクは非公開で開けない旨を説明します。
- 実測のID、検索条件、日時、直接確認した数値で追跡します。ハッシュ値、画像照合値、指紋、Cookie値は使いません。

## Git除外の実行結果

- `.gitignore`へ`/非公開作業データ/`を追加しました。このルールは作業ルート直下の非公開データだけを対象にします。
- 既存の`.gitignore`の他の行は変更していません。対象の既追跡ファイルはありませんでした。
- `非公開作業データ/`に、実標本を含まない一時ファイル`_git-exclusion-check.txt`を実際に作成して確認しました。`git check-ignore -v`は`.gitignore`の7行目の`/非公開作業データ/`への一致を返し、`git status --short --ignored`は`!! 非公開作業データ/_git-exclusion-check.txt`と表示しました。確認後、一時ファイルを削除しました。
- 除外対象となる専用フォルダと`基礎/本文/`を作成しました。検索前にこのルートの除外が実ファイルで働くことを確かめ、Cookie・トークン・認証ファイル・他のローカル運用データを移動またはコピーしていません。
- 今回Gitに記録するのは公開用方針と`.gitignore`の除外行だけです。原観測用のディレクトリ内は空のままです。
