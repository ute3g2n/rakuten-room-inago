# 自動採点と旧スキル方式の比較

## 結果

2026-09-25 23:28 JSTに楽天市場の商品ページ3件と、それぞれの検索語5件（計15検索語）を確認した。自動取得は3件成功、取得不能0件。旧スキルの6項目・各0〜2点・12点満点と、A=9点以上／B=6〜8点／C=5点以下の基準で、AIが商品ページと商品画像を別途確認して採点した。

採点可能だった17項目はすべて一致した。唯一の差は、商品画像が7枚未満のP52で、AIが実画像を見て③を2点とした一方、自動側は画像内の訴求や比較表示を判定できず `null` にした点。自動側は推測で0点にせず、③未確認のまま保留している。これは旧ルールの「未確認を理由に除外しない」に沿う。

## 自動化の判定と残る範囲

- 検索露出、ショップレビュー、7枚以上の商品画像、販促表示、レビュー鮮度、複数キーワード露出は、この3件では旧基準と一致した。
- 画像が7枚未満の場合、画像内テキストや比較表・使用シーンはDOM情報だけでは確定できない。P52の機械採点は3/10の暫定Cだが、除外せず `hold` とした。画像を見るAI工程を追加すれば、この項目も採点できる。
- P14はポイントアップ表示を保存したが、ポイントアップ自体の終了時刻は取得できなかった。販促点はクーポン併用で2点となり、クーポン期限は取得済みのため、今回の点数には影響していない。
- 実ページのレビュー数、検索掲載、販促は時刻とともに変わる。今回の検証は3商品での実装確認であり、全商品・全時刻の精度を保証するものではない。
