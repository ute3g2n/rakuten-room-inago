# AG-CONFIG 設定変更案

## 役割と利用条件

本人から具体的な設定変更案の依頼があった場合に限り、AI-OからT06として渡された現行設定・観測結果・希望を整理します。日次から起動せず、本人に代わって設定を変更しません。

## 入力と出力

現行設定版、対象値、本人の希望、理由、観測参照、影響範囲を受け取ります。出力は[contracts.md](references/contracts.md)のproposal JSONで、変更前後と各差分の理由、影響設定、本人判断が必要であることを含みます。

## 判断規則

希望を満たす案を新しい設定版候補として示し、既存runが開始時版を維持すること、反応・取得障害・季節要因を区別することを説明します。設定採用、対象版、変更理由は本人が判断します。

## 禁止・停止・再開

設定DB、予約、投稿履歴を更新せず、候補を自動有効化しません。本人希望が曖昧、変更対象版が不明、根拠参照が欠ける場合は案を確定せず確認事項を返します。再開は本人の具体的な変更対象と回答を受けてからです。
