# 既存ROOMの診断＆分析（ルートB専用手順）

目的：ユーザーの楽天ROOM（URL）を実際に読み、「どこで評価の流れが切れているか」を特定し、**最優先で直す1点**まで落とし込む。判断基準はすべて `methodology.md` に従う。

## 1. 情報収集

**URLの受け取りと正規化：**
- ユーザーROOMのURL形式は `https://room.rakuten.co.jp/<room_xxxx等のID>/items`。`/items` なし・スマホ共有URLでも受け付け、`<ID>/items` に正規化して開く。

**実読する（ブラウザツール優先。検証済みの取得手順）：**
公開ROOMはログイン不要。**ブラウザツール（アプリ内ブラウザ／CodexのBrowser/Chrome拡張機能等）で開くのが第一選択**（ページはJSレンダリングのため、単純なHTTP取得では投稿一覧が取れない）。
1. **自己紹介文**：ページの `meta[name=description]`（og:description）に全文が入っている。JS実行が使えるなら `document.querySelector('meta[name=description]').content` で一発取得。WebFetchでもこのメタ情報だけは取れる
2. **プロフィールヘッダー**：ユーザー名／フォロー数／フォロワー数／商品数／コーディネート・コレクション数（ページテキスト先頭に出る）
3. **投稿一覧**：ページテキスト取得で直近投稿の「投稿文全文・価格・いいね数・`#PR`/`#オリジナル写真` タグ」が読める。スクロールして**直近10〜30件**を確保する
4. アイコン・棚の見た目の印象はスクリーンショットで確認
5. 一覧だけで商品名や本人の紹介文が読めない場合は、本人の投稿詳細を開く。販売店の商品タイトルと本人の紹介文を分け、「その他のおすすめ関連投稿」など他人の投稿は集計しない。本人の文章が表示されない場合は「表示なし」と記録し、商品タイトルを紹介文とみなさない。

この取得データで分析できること：価格帯分布（表示価格から）／ジャンル分布と一貫性（商品名・投稿文から）／冒頭40〜45文字の質（投稿文冒頭から）／日記投稿・売り込み度／PR案件比率／いいね数の偏り（どの投稿構造が刺さっているか）。

### URL確認後に画面表示する6項目（この順序）

取得内容を内部で整理するだけでなく、ヒアリングの前に必ずユーザーへ表示する。

| 表示項目 | 表示する内容 |
|---|---|
| プロフィール | 現在の名前・自己紹介・対象読者。読めた範囲のアイコンの印象 |
| 投稿ジャンル | 読めた投稿の商品ジャンル別件数・割合 |
| 直近投稿 | 確認した件数・代表的な商品と投稿文。全文が読めない場合はその旨 |
| 商品の価格帯 | 表示価格の分布。範囲価格・最安選択肢は単品の確定価格と区別 |
| 投稿の偏り | 同ジャンル・商品・文章型・役割への偏りを件数と例で示す |
| 反応の傾向 | 公開のいいね・コメント数など。クリック・購入・売上は本人回答が必要と明示 |

各項目は観測事実を中心に簡潔に書く。未確認の項目も見出しを残して理由を添える。反応が少ない場合は傾向を断定しない。公開のいいね数から売上や購入を推定しない。読めた投稿数／取得失敗数を添え、プロフィールと商品数だけの確認を6項目の整理完了とは扱わない。

### 現状整理を表示した後に聞く5項目

- **A：運用歴** — 例：始めて2週間／3か月／1年。
- **B：1日の投稿量** — 例：1日1件／1日3件／週3件程度。毎日でなくても実際のペースを受け付ける。
- **C：売上状況** — 例：まだ売上なし／月に数件売れる／以前より減っている。未把握なら「未確認」として受け付け、売上ゼロとみなさない。
- **D：商品選定方法** — 例：実際に使っている物／楽天市場の検索／ROOMのランキング／SNSで見つけた物。
- **E：現在困っていること** — 例：クリックされない／購入につながらない／紹介する商品の方向性に迷う。「特になし」も本人回答として受け付ける。

5項目を一つの回答フォームまたは2〜3問ずつのまとまりで提示する。質問数の上限を守りつつ、5項目を欠かさない。会話・保存済みデータに今回も有効な回答があれば表示して引き継ぎ、未回答だけ聞く。初回ルートAの必須回答ルールをこの診断ヒアリングに流用しない。本人が分からない数値を無理に埋めさせない。

回答を受け取ってから§3の診断結果を出す。未確認と回答された部分は診断から除外し、暫定と明示する。投稿時刻や交流に使う時間などの追加質問は、診断に必要な場合だけ行い、上記5項目の代わりにしない。

**フォールバック：** ROOMページが読めない/JSで内容が取れない場合は創作せず、①プロフィール文のコピー ②直近投稿5〜10件の「商品名＋投稿文」コピーかスクショ を貼ってもらう。それでも不足する項目は「未確認」として診断から除外を明示。

## 2. 診断票（6分野）

各分野を ◎（問題なし）／△（ズレあり）／✕（致命的）で判定し、**必ず実際に見た文言・投稿を根拠として引用**する。見られなかった分野は「未確認」。

**印象で書かない。数えた結果を必ず数値で添える。** 直近投稿を読めているなら、少なくとも次は数える：

| 分野 | 数えるもの | 書き方の例 |
|---|---|---|
| 分野2 ジャンル一貫性 | 直近30投稿をジャンル分類し、メインの占有率 | 「直近30件：美容17／食品8／家電5 → メイン57%（目標6〜7割に未達）」 |
| 分野3 価格帯 | 直近30投稿の価格分布 | 「1,000円未満4／1,000〜3,000円11／3,000〜5,000円6／5,000円超9 → 黄金帯37%」 |
| 分野4 投稿文 | 冒頭がフックになっている投稿の件数、「購入はこちら」等のNG出現数 | 「冒頭フック該当 6/30件。『購入はこちら』3件」 |
| 分野5 役割と導線 | 回遊3点セットが成立している箇所数、末尾に次への誘導がある投稿数 | 「3点セット成立0箇所／次行動導線あり2/30件」 |

読めた投稿数も明記する（例：**「直近28件を読めました／⚠取得失敗2件」**）。読めた件数が10件未満なら、診断は「暫定」と明示してからフォールバック（コピー/スクショ）を依頼する。

### 分野1｜プロフィール設計
- ユーザー名が「誰向け×何ジャンル」になっているか（ニックネームだけ・絵文字だけは✕）
- 自己紹介文が2〜4行で、誰の・どんな悩みに・何ジャンルで答えるかを言えているか（自分語り/実績アピールのみ＝日記アカウント判定リスク）
- アイコンからジャンルが連想できるか（自撮り・風景は△）

### 分野2｜ジャンル一貫性
- メイン1＋サブ2に収まっているか。メインが投稿の6〜7割か
- 悩みが1本で繋がっているか（コスメ＋家電＋食品の混在＝ジャンル迷子ROOM判定で✕）
- 逆に狭すぎないか（同種商品しか載せず回遊の広がりを自分で潰していないか）

### 分野3｜価格帯
- 単品1,000〜3,000円の黄金帯が中心か
- 5,000円超の連発／500〜900円の安物ばかり（利益破壊サイクル）になっていないか
- 関連セットで購買単価を上げる設計があるか

### 分野4｜投稿文
- 冒頭40〜45文字がフックになっているか（「今回ご紹介するのは◯◯です」型は✕）
- 「誰の・どんな悩みが・どう変わるか」の未来提示があるか（商品名＋スペック＋「人気です」だけの日記投稿は✕）
- 「購入はこちら」等のROOM完結誘導がないか（あれば✕・最優先修正候補）
- 比較文脈の質：比較軸1本に絞れているか（説明が長いだけ／選択肢を並べて迷わせるだけは△）
- AI生成文をそのまま貼った形跡（不自然な網羅・定型連発）はないか

### 分野5｜役割と導線
- 投稿に役割の使い分けがあるか（全部が全力売り込み＝✕。アルゴリズムに最も嫌われる）
- 回遊3点セット（入口→関連→収益拡張）が揃っている箇所があるか。1投稿1商品で完結し、末尾に次への誘導がないか
- 予告・再訪の仕掛けがあるか（30投稿以上の運用歴があるのに皆無なら△）
- 並び順が棚として自然か（高級品の隣に激安品などブランド破壊がないか）

### 分野6｜選定源と時間帯（ヒアリングベース）
- 商品をROOM内ランキング/おすすめから選んでいないか（「後追いの墓場」）
- 投稿時間が20〜23時（または朝6〜8時・昼12〜13時）に乗っているか。「空いた時間に投稿」は✕
- いいね周り・フォロー周りに時間を割いていないか
- 反応の数字（クリック・閲覧）を見て修正しているか（感覚修正は✕）

## 3. 診断レポートの形式

```
# ROOM診断レポート（YYYY-MM-DD）
対象：<ROOM URL>（✅実ページ確認 or 一部ユーザー提供情報）

## 今のROOMの良い点
- …（根拠付き）

## ズレている点
| 分野 | 判定 | 根拠（実際に見たもの） | 該当する失敗パターン |
|---|---|---|---|

## 最優先で直すポイント
<1つだけ。理由と、直すと何が変わるか>
※修正は一度に1つ。直したら数字（クリック・反応）を見てから次へ。

## 既存ROOMの改善案（3つの診断結果の後に提示）
- ターゲット再定義： / メイン1＋サブ2： / ユーザー名案： / 自己紹介文案：
- 既存投稿の扱い：良い点を残し、必要な修正だけを提案する。新しいROOMの作成や一括削除を前提にしない。
  ジャンル外の直近投稿のみ整理を検討。伸びた投稿があればその構造を横展開の起点にする。

## 今後2週間の修正ロードマップ
- Week1：最優先の1点を直す＋固定候補リスト作成＋3役テンプレ準備
- Week2：反応メモを取りながら刺さるパターンに寄せる
```

診断の主要見出しは「今のROOMの良い点」「ズレている点」「最優先で直すポイント」の3つをこの順で表示する。改善案では、その1点をどう修正するかを具体化する。ジャンル比率・ターゲット・候補商品の価格帯・入口／比較／回収の役割は、診断に該当したものだけ見直す。原稿のナレーションや「【画面表示】」という文字は出力しない。

## 4. 診断時の心得

- 断定できないことは断定しない。「楽天の内部仕様」は原則💭推定として扱い、observable な事実（投稿・文言・並び）を根拠の中心にする。
- ダメ出しの列挙にしない。「良い点→ズレ→最優先の1点」の順で、次の行動が1つに絞れる形で渡す。
- 実績金額の約束はしない。

## 5. 診断後の合流

改善方針を確定・保存したら、SKILL.mdのSTEP C→D→Eへ進む。商品選定・投稿文には診断で残すと決めた良い点と最優先の修正点を引き継ぐ。既存ROOMの一括作り直しを行わない。設定済みルーチンがあればその設定を確認して継続し、同じ時刻のルーチンを追加しない。
